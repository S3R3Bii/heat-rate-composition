# Source schema clarified before value inspection

All seven official annual archives were retrieved after public protocol b18909d. Only workbook/sheet names, metadata, header rows and the Page7 file-layout dictionary were inspected before this mapping. Every target workbook uses header row6 on **Page 1 Generation and Fuel Data**. Page1 Puerto Rico and Page1 Energy Storage are separate sheets and are excluded from this fixed fuel analysis. An initial overly broad sheet-name selector matched those extra sheets and stopped before value rows; the exact documented sheet was selected on one targeted correction. Cached original bodies were reused. Original file-write timestamps and hashes are retained; initial failed parsing did not retain HTTP response headers, which is disclosed rather than invented.

Use annual **Elec Fuel Consumption MMBtu** and **Net Generation (Megawatthours)**. The layout defines them as year-to-date electricity fuel consumption and net electrical output less station service; all selected files are December/final annual workbooks. It identifies CHP status as Y/N and gives the prime-mover dictionary. The AER/MER aggregate fuel-code header changed in2022; this study uses the unchanged **Reported Fuel Type Code** field. No outcome-dependent field selection occurs.

Combined-cycle component definitions CA/CT/CS are confirmed in both older/current dictionaries and the official instructions. The projection additionally retains WH (waste heat) rows **for a source-boundary diagnostic only**. WH output is not assigned to NG or coal without a documented allocation, and no engineering cycle efficiency is inferred. Before analysis, report whether WH/CA output occurs at plants also reporting selected NG/coal. All primary filters,72 cases, decomposition formulas, numerical tolerances and cohorts remain fixed. Technology aggregation combines the **selected reported-fuel-coded** CA/CT/CS rows; it does not invent a fuel attribution for unassigned waste heat. Even after aggregation, within-cell change may reflect internal technology/load/co-fuel allocation changes.
